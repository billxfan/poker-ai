# Poker AI Web 单机版

[English](./README.md) · [返回仓库首页](../README.zh-Hans.md)

这是独立的离线优先网页客户端：一名玩家与五名本地 AI 对手进行 6 人桌
无限注德州扑克训练。无需账号、登录、后端或网络服务。

原有 iOS App 仍位于仓库根目录。网页端拥有独立的源码、构建工具和
浏览器本地存档，不会引用 iOS 工程中的广告、统计或云服务。

## 功能范围

- 6 人桌无限注德州扑克
- 5 个拥有不同风格与学习曲线的本地 AI
- 弃牌、过牌/跟注、加注和全下
- 主池、边池、平分底池与完整结算明细
- AI 思考节奏、自动补码与离线游戏音效
- 最近手牌、对手画像、历史统计与术语解释
- 响应式桌面端与移动浏览器布局
- 浏览器本地自动存档与可安装 PWA
- 无登录、无多人、无真钱、无广告、无云同步

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
```

该命令会运行德扑核心逻辑回归测试并验证生产构建。
