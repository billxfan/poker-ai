# 猫咪牌馆：牌组美术方向

> 52 张逐牌定义、生图顺序与验收清单见
> [cat-deck-52-card-brief.md](./cat-deck-52-card-brief.md)。本文保留牌组的基础规则。

## 牌组范围

- 德州扑克使用 52 张标准牌，不包含大小王。
- 点数和花色由网页代码绘制，生成图片中不包含任何文字、数字或花色符号。
- 猫咪插画只承担角色和世界观表达，不能替代牌面识别信息。
- 每张插画使用稳定的竖向胸像构图，主体集中在中央，四周保留裁切安全区。

## 视觉基调

牌组采用“精品桌游插画 + 轻雕塑感”的风格：成熟、温暖、有幽默感，但不做
幼儿卡通。猫咪保留真实品种特征，毛发以简化的立体块面表现，服装使用有触感
的织物、皮革和金属细节。光照统一为柔和的牌馆侧光，背景使用低对比度的拱形
室内或抽象纹理，避免复杂场景影响小尺寸阅读。

所有插画必须满足：

- 单只猫，胸像或半身，正面或轻微三分之二角度。
- 眼睛、耳朵和轮廓在缩小后仍清楚。
- 无文字、无数字、无花色符号、无边框、无水印。
- 不出现扑克牌、筹码、手部畸形或额外动物。
- 服装不能遮挡猫咪最有辨识度的品种特征。

## 小尺寸牌面结构

网页继续负责左上和右下的点数、花色以及高对比度角标。猫咪插画使用圆角
满版裁切，并叠加顶部、底部渐变，保证点数与角色同时可读：

- 常规牌：显示头部、肩部和部分服装，保留双角标。
- 紧凑牌：优先显示猫咪头部和耳朵，只保留左上角标以减少遮挡。
- 历史记录中的 30px 小牌保留品种轮廓、家族主色、点数和花色。

## 首轮验证集

首轮只制作 4 张 A：

1. 黑桃 A：夜巡会缅因猫
2. 红桃 A：暖炉社缅因猫
3. 方块 A：金库庭缅因猫
4. 梅花 A：苔原团缅因猫

验证通过后再扩展 J、Q、K，最后补齐 2–10。这样可以先验证同一品种在四个
花色家族中的一致性，再验证不同品种之间的可识别度。


```text

```

- Service Worker 安装时预缓存完整牌组，首次加载完成后可离线使用全部牌面。
- 自动测试校验 52 个映射唯一、文件存在、没有大小王，并保持 `10` 而非 `T`。
