## 已知边界与后续优先级

- 当前策略是牌力分桶、位置、价格、SPR、人数、牌面湿度、主动权、公开行动与
  逐对手 read 共同驱动的有界 contextual bandit，不是范围权益或 GTO 求解器。
- 尚未完整建模每次下注尺寸序列和对手范围；局后解释来自真实 trace，但只展示
  少量关键公开因素。
- 仓库人格测试应在下一版补充“同一 observation 仅替换 style”的正式 fixture，
  并增加五人格长程分布分类回归。
- 移动端角色与下注小字可继续放大，中央留白可进一步压缩；当前不阻塞操作。
- 少数长牌局的累计等待仍可能接近 40 秒；可在 v0.3 增加可选 Turbo 模式。
