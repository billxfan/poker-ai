## 音频边界

- 所有声音只订阅已接受的公开演出事件；非法动作不会提前发声。
- 同一事件 ID 只播放一次。
- 发牌、过牌、跟注、加注、弃牌、全下、翻牌、转牌、河牌、摊牌、收池、
  轮到玩家、获胜与失利均有不同语义声音。
- 高频声音依据稳定事件 ID 调整音高、节奏、摩擦音色或筹码密度，避免连续动作
  完全同音。
- 环境声是独立的低通房间底噪层，默认关闭；隐藏页面或离开牌桌时停止。
