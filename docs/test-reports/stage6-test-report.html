测试发现与修复

已修复

HandType 比较运算符反转

问题：HandType 的 < 和 > 运算符实现反了，导致 highCard > onePair > twoPair ... 的错误顺序。

修复：交换了比较运算符中的 rawValue 比较方向。

已修复

皇家同花顺错误识别

问题：A-2-3-4-5 顺子（wheel）被错误地识别为皇家同花顺，因为代码只检查是否有 A（14）。

修复：添加了 isWheelStraight() 辅助函数，并在顺子判断中特殊处理 wheel 情况（高牌为5而非14）。

已修复

HoleCards 类型统一

问题：项目中使用 (Card, Card)? 元组类型不符合 Codable，导致部分模型无法正确序列化。

修复：引入了 HoleCards 结构体替代元组，并更新了所有相关文件。

已添加

单元测试覆盖

内容：新增 22 个单元测试，覆盖核心模型和手牌评估逻辑，包括：

  • Card 模型测试（7个）
  • HandEvaluator 手牌评估测试（13个）
  • HandType 枚举测试（2个）
已解决

UI 截图显示问题的调查结论

  • 当 chips=0 时，"新开始"按钮会被禁用（disabled）
  • 完整卸载重装后，App 正确显示 2,000 筹码和"今日已到账"状态

结论：App UI 正常工作，无阻塞性 bug。
