## 每日福利项目

### 1. 每日免费领筹码（自动）

| 项目 | 说明 |
|------|------|
| 奖励数量 | 2,000 筹码 |
| 领取方式 | **每日自动到账**，无需手动操作 |
| 重置时间 | 每日凌晨 00:00 |

### 2. 每日签到

| 项目 | 说明 |
|------|------|
| 奖励数量 | 1,000 筹码 |
| 领取方式 | 手动点击按钮领取 |
| 重置时间 | 每日凌晨 00:00 |

### 3. 看广告领筹码（预留）

| 项目 | 说明 |
|------|------|
| 奖励数量 | 待定（可配置） |
| 领取方式 | 观看广告视频 |
| 状态 | **开发中**，暂不开放 |
| 用途 | 后续接入广告变现 |

## 数据存储

| 数据 | 存储位置 | 说明 |
|------|---------|------|
| 每日免费领取状态 | UserDefaults | 今日是否已领取 |
| 每日签到状态 | UserDefaults | 今日是否已签到 |
| 上次领取时间戳 | UserDefaults | 用于判断是否跨天 |
| 累计领取筹码 | SQLite | 统计用 |

## 每日重置逻辑

```
每次进入福利中心 或 每日凌晨检查：

if (今天 != 上次领取日期) {
    重置每日免费领取状态 = 未领取
    重置每日签到状态 = 未签到
    更新上次领取日期 = 今天
}
```

## 状态机

### WelfareView

| 当前状态 | 触发事件 | 动作 | 下一状态 |
|---------|---------|------|---------|
| idle | 进入页面 | 检查每日福利状态 | checking |
| checking | 有可领取福利 | 显示可领取状态 | canClaim |
| checking | 无可领取福利 | 显示明日再来 | allClaimed |
| canClaim | 点击签到按钮 | 发放筹码，显示成功弹窗 | claimed |
| claimed | 点击确定 | 关闭弹窗，刷新状态 | allClaimed |
| allClaimed | 点击返回 | 返回主页 | dismissed |

## Definition of Done

- [ ] 每日免费筹码自动到账正确

- [ ] 签到成功后正确发放筹码
- [ ] 已领取后正确显示明日再来
- [ ] 凌晨 00:00 正确重置所有状态
- [ ] 广告功能预留入口（暂不开放）
- [ ] 页面返回后主页面筹码正确更新
