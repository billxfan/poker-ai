## 技术实现要点

| 模块 | 技术要点 |
|------|---------|
| 主页面 | SwiftUI NavigationStack，同尺寸按钮，颜色差异化，emoji图标 |
| 对局页面 | SwiftUI 竖屏布局，动画，实时状态更新 |
| 福利中心 | UserDefaults 存储领取状态，每日重置逻辑 |
| 统计页面 | SwiftUI TabView，Swift Charts 折线图，最近30手完整公开信息展示 |
| AI 系统 | 规则引擎（硬编码参数 + ε-greedy），SQLite 存储对手画像 |
| 规则引擎 | 牌型判定算法（A-2-3-4-5特殊处理），边池递归分配 |

## 竖屏布局说明

游戏采用**竖屏布局**：
- 人类玩家在底部中央
- AI-1 到 AI-5 顺时针分布在上方
- 操作按钮在底部
- 右侧可滑动面板显示行动记录
