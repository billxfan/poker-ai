# 对局页面（GameView）

## 功能

6人局德扑对战界面，椭圆形牌桌俯视布局，人类玩家在底部中央，AI-1 到 AI-5 均匀分布在牌桌边缘。

## 玩家信息卡

每个玩家位置显示：

```
┌────────────────┐
│  💭 思考中... │  ← 思考气泡（AI思考时显示）
│    ████        │  ← 随机1-3秒
└────┬───────────┘
     │
┌────┴───────────┐
│     👴          │  ← 圆形头像
│    老K          │  ← AI昵称
│  筹码: 3000    │  ← 剩余筹码
│    ♠♡          │  ← 手牌（未发牌显示??）
│   👆跟注 150   │  ← 当前动作状态
└─────────────────┘
```

### 状态标签

| 状态 | 显示 |
|------|------|
| 思考中 | 💭 思考中...（气泡，1-3秒随机） |
| 已弃牌 | ❌ 弃牌 |
| 全下 | 🔥 全下 500 |
| 跟注 | 👆 跟注 150 |
| 加注 | ⬆️ 加注 300 |
| 下注 | • 下注 100 |
| 等待 | ⏳ 等待 |

### AI思考气泡

为 AI 正在思考时，头像上方显示气泡：

```
      ┌──────────┐
      │💭 思考中...│  ← 气泡
      │   ████   │  ← 随机1-3秒
      └────┬─────┘
           │
      ┌────┴────┐
      │  AI-2   │
      │  🧑     │
      └─────────┘
```

- 气泡随机显示 1-3 秒
- 气泡消失后，AI 动作显示在头像旁边
- 德扑顺序行动，**同一时刻只有一个AI在思考**，等待完成后轮到下一个

## 操作按钮区

### 按钮尺寸（统一）

所有按钮相同尺寸（宽度均分，高度48pt），通过颜色区分：

```
┌──────────────────────────────────────────────────┐
│                                                   │
│   弃牌      跟注 150      +加注       全下 2500   │
│   🔴         🟢150        🟡         🟠2500      │
│                                                   │
└──────────────────────────────────────────────────┘
```

### 按钮状态

| 按钮 | 条件 | 状态 | 颜色 |
|------|------|------|------|
| **弃牌** | 任何时候 | 可点击 | 🔴 红色 |
| **跟注** | 需跟注且筹码够 | 可点击 + 显示金额 | 🟢 绿色 |
| **跟注** | 需跟注但筹码不够 | **置灰禁用** | ⚫ 灰色 |
| **加注** | 可加注且筹码够 | 可点击 | 🟡 黄色 |
| **加注** | 可加注但筹码不够 | **置灰禁用** | ⚫ 灰色 |
| **全下** | 筹码 > 0 | 可点击 + 显示金额 | 🟠 橙色 |
| **全下** | 筹码 = 0 | **置灰禁用** | ⚫ 灰色 |
| **过牌** | 无需跟注时显示（替代跟注） | 可点击 | 🟢 绿色 |

## 状态机

### GameView

| 当前状态 | 触发事件 | 动作 | 下一状态 |
|---------|---------|------|---------|
| idle | 进入页面 | 初始化牌桌 | dealing |
| dealing | 发牌完成 | 显示玩家状态 | waitingForAction |
| waitingForAction | 轮到玩家 | 检测筹码，显示操作栏 | playerActing |
| waitingForAction | 轮到AI | AI显示思考气泡 | aiThinking |
| aiThinking | 气泡消失(1-3s) | 记录AI动作，隐藏气泡 | checkingRoundEnd |
| checkingRoundEnd | 有人未行动 | 轮到下一人 | waitingForAction |
| checkingRoundEnd | 所有人行动完毕 | 判定下一轮或摊牌 | roundTransition |
| playerActing | 玩家弃牌 | 记录动作 | checkingRoundEnd |
| playerActing | 玩家跟注 | 记录动作，更新底池 | checkingRoundEnd |
| playerActing | 玩家加注 | 记录动作，更新底池 | checkingRoundEnd |
| playerActing | 玩家全下 | 记录动作，触发边池计算 | checkingRoundEnd |
| roundTransition | 需发牌 | 发一张/多张公共牌 | waitingForAction |
| roundTransition | 局结束 | 显示摊牌结果弹窗 | roundEnd |
| roundEnd | 点击下一局 | 重置本局状态 | dealing |
| roundEnd | 点击返回主页 | 保存战绩 | dismissed |

### 筹码不足检测

| 触发时机 | 检测内容 | 动作 |
|---------|---------|------|
| 进入playerActing | 需跟注金额 vs 用户筹码 | 跟注按钮置灰 |
| 进入playerActing | 最小加注额 vs 用户筹码 | 加注按钮置灰 |
| 进入playerActing | 用户筹码 vs 0 | 全下按钮置灰 |

## 异常处理

| 场景 | 策略 |
|------|------|
| 用户筹码不足跟注 | 跟注/加注按钮置灰，只能弃牌或全下 |
| 用户全下但低于最低加注 | 自动转为跟注（全下额） |
| AI思考 | 轮到这个AI时显示气泡，1-3秒后消失 |
| 应用中断（来电/锁屏） | 自动保存当前状态 |
| 恢复后 | 加载存档，恢复到断点 |
