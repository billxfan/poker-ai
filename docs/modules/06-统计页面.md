# 统计页面（StatisticsView）

## 功能

展示玩家的对局数据统计和近期牌局记录，分两个 Tab 切换。

## 页面结构（2个Tab）

```
┌─────────────────────────────┐
│  ← 返回      我的统计        │
├─────────────────────────────┤
│                             │
│  ┌───────────┬───────────┐ │
│  │  📊 数据  │  🃏 最近  │ │  ← Tab 切换
│  │    统计   │    30手   │ │
│  └───────────┴───────────┘ │
│                             │
│  ════════════════════════  │  ← 选中指示条
│                             │
├─────────────────────────────┤
│                             │
│       [当前Tab内容]          │
│                             │
└─────────────────────────────┘
```

## 状态机

### StatisticsView

| 当前状态 | 触发事件 | 动作 | 下一状态 |
|---------|---------|------|---------|
| idle | 进入页面 | 加载统计数据 | loading |
| loading | 加载成功 | 显示Tab1(数据统计) | success |
| loading | 加载失败 | 显示错误 | error |
| success | 点击Tab1 | 切换到数据统计 | tab1 |
| success | 点击Tab2 | 加载最近30手数据 | loadingHands |
| loadingHands | 加载成功 | 切换到Tab2 | tab2 |
| tab2 | 点击Tab1 | 切换到数据统计 | tab1 |
| tab1 / tab2 | 点击返回 | 返回主页 | dismissed |

## 数据模型

### 单手记录

```swift
struct HandRecord {
    id: Int              // 局号
    result: Result       // 胜/负/平
    profit: Int          // 盈亏筹码

    // 公共信息
    publicCards: [Card]  // 公共牌（可能未发完）
    pot: Int            // 底池金额

    // 玩家信息
    playerHoleCards: Card?  // 自己的手牌（若摊牌）
    playerHandType: HandType?  // 自己的牌型（若摊牌）

    // 行动记录
    actions: [Action]   // 每轮行动列表

    // 结果
    winner: Player      // 获胜者
    showdown: Bool      // 是否摊牌
}
```

### 行动记录

```swift
struct Action {
    player: Player       // 玩家
    street: Street       // 预翻牌/翻牌/转牌/河牌
    action: ActionType   // 弃牌/跟注/加注/全下
    amount: Int?         // 金额（若有）
}
```
