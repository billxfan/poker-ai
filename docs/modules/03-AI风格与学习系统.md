# AI 风格与学习系统

## 功能

5 个 AI 对手，各有独特风格，通过规则引擎驱动决策，并通过统计数据适应玩家打法。

## AI 角色配置（硬编码）

| AI编号 | 昵称 | 头像 | 风格 | 入局率 | 学习率 | 记忆周期 | 调整上限 |
|--------|------|------|------|--------|--------|---------|---------|
| AI-1 | 老K | 👴（沉稳老人） | 紧凶型（TAG） | 20-25% | 0.3 | 50局 | 15% |
| AI-2 | 小马 | 🧑（活泼青年） | 松凶型（LAG） | 40-45% | 0.5 | 30局 | 30% |
| AI-3 | 大叔 | 🧔（中年商人） | 紧弱型（TP） | 15-20% | 0.1 | 20局 | 5% |
| AI-4 | 小鱼 | 👧（新手女孩） | 松弱型（LP） | 50-55% | 0.05 | 10局 | 3% |
| AI-5 | 狐狸 | 🦊（神秘狐狸） | 平衡型 | 30-35% | 0.4 | 60局 | 25% |

### AI 头像说明

| AI | 昵称 | 头像描述 | 性格暗示 |
|----|------|---------|---------|
| AI-1 | 老K | 沉稳的老人头像 | 经验丰富，打法稳重紧凶 |
| AI-2 | 小马 | 活泼的青年头像 | 激进爱诈唬，松凶风格 |
| AI-3 | 大叔 | 中年商人头像 | 有牌就守，但容易被诈唬 |
| AI-4 | 小鱼 | 新手女孩头像 | 打法松弱，喜欢跟注 |
| AI-5 | 狐狸 | 神秘的狐狸头像 | 难以捉摸，平衡型打法 |

### 风格定义

| 风格 | 特征 |
|------|------|
| **紧凶型（TAG）** | 只玩强牌，入池后攻击性强，很少跟注，几乎不诈唬 |
| **松凶型（LAG）** | 玩大量边缘牌，频繁加注诈唬，喜欢听牌半诈唬 |
| **紧弱型（TP）** | 只玩顶级牌，几乎不诈唬，有牌就跟注，容易被诈唬 |
| **松弱型（LP）** | 玩很多弱牌，几乎不加注，喜欢跟注到摊牌 |
| **平衡型** | 混合强牌与诈唬，根据位置调整，根据对手调整 |

## 规则引擎决策流程

```
┌─────────────────────────────────────────┐
│           AI 决策流程                   │
├─────────────────────────────────────────┤
│ 1. 获取可观测信息                        │
│    - 自己的2张底牌                       │
│    - 已发出的公共牌                       │
│    - 本局所有玩家的历史动作               │
│    - 当前底池金额                        │
│    - 需跟注金额                         │
├─────────────────────────────────────────┤
│ 2. 计算基础决策概率                       │
│    弃牌概率 = f(牌力, 位置, 紧松度)       │
│    跟注概率 = f(牌力, 底池赔率, 凶弱度)   │
│    加注概率 = f(牌力, 位置, 玩家特征, 凶弱度)│
├─────────────────────────────────────────┤
│ 3. ε-greedy 探索                        │
│    - 概率(1-ε): 选择最高概率动作         │
│    - 概率(ε): 随机选择动作               │
│      （模拟真人不可预测性）               │
├─────────────────────────────────────────┤
│ 4. 输出决策（弃牌/跟注/加注/全下）        │
└─────────────────────────────────────────┘
```

### ε 值设定

| AI风格 | 初始 ε | 最低 ε | 衰减方式 |
|--------|--------|--------|---------|
| 紧凶型 | 0.3 | 0.05 | 每50局衰减20% |
| 松凶型 | 0.4 | 0.1 | 每30局衰减15% |
| 紧弱型 | 0.2 | 0.05 | 每20局衰减10% |
| 松弱型 | 0.35 | 0.15 | 每10局衰减10% |
| 平衡型 | 0.3 | 0.08 | 每60局衰减18% |

## 学习系统

### 学习对象

每个 AI 会学习：
- **人类玩家**（主要）
- **其他4个AI**

### 可学习的信息（可观测）

每个 AI 只能使用自己「亲眼看到」的信息：

1. 自己的 2 张底牌
2. 所有已发出的公共牌
3. 本局所有人的下注动作（弃牌/跟注/加注/全下）
4. 摊牌时其他玩家亮出的底牌
5. 历史所有玩家的动作频率统计

**禁止**：访问其他玩家的隐藏底牌、查看未来公共牌

### 学习触发

**每局结束后**，AI 执行以下分析：

```
每局结束 → 记录本局动作 → 更新历史统计 →
每N局 → 分析对手画像 → 调整自身参数
```

### 对手画像

针对每个对手（玩家或AI），维护以下统计：

| 统计项 | 说明 |
|--------|------|
| 入局率 | 参与牌局的概率 |
| 加注率 | 加注的频率 |
| 弃牌率 | 面对下注时弃牌的频率 |
| 诈唬频率 | 纯诈唬（下注无牌）出现的频率 |
| 跟注率 | 面对加注时跟注的频率 |

### 参数调整

```
调整幅度 = 学习率 × 对手暴露度 × 调整上限

对手暴露度 = |实际动作频率 - 预期频率|
```

**调整方向**：

| AI发现 | 调整策略 |
|--------|---------|
| 玩家频繁诈唬 | 提高跟注频率（紧凶型 +15%，平衡型 +10%） |
| 玩家紧弱 | 提高诈唬频率（松凶型 +20%，平衡型 +15%） |
| 玩家频繁弃牌 | 提高持续下注频率（所有风格） |
| 玩家跟注率高 | 减少诈唬，专注价值下注 |

### 学习率衰减

```
当前学习率 = 初始学习率 × (0.9 ^ 已学习局数)
```

学习率随局数增加逐渐衰减，防止 AI 过度适应短期波动。

## AI 思考延迟

| AI风格 | 延迟范围 | 说明 |
|--------|---------|------|
| 紧凶型 | 0.5-0.8s | 决策快，决策自信 |
| 松凶型 | 1.0-1.5s | 决策慢，考虑诈唬选项 |
| 紧弱型 | 0.5-0.7s | 决策快，依赖手牌强度 |
| 松弱型 | 0.8-1.2s | 决策慢，喜欢跟注 |
| 平衡型 | 0.6-1.0s | 中等速度 |

## AI 行为表现

| 阶段 | AI-1(紧凶) | AI-2(松凶) | AI-3(紧弱) | AI-4(松弱) | AI-5(平衡) |
|------|-----------|-----------|-----------|-----------|-----------|
| 初期 | 紧，+强牌必加 | 松，频繁诈唬 | 紧，只玩AA/KK | 松弱，+跟到底 | 适中，+观察调整 |
| 中期 | 开始识别紧弱 | 更激进的半诈 | 开始跟注更多 | 更爱跟注 | 识别玩家风格 |
| 后期 | 针对玩家优化 | 针对紧弱加诈 | 针对松凶跟注 | 针对紧凶弃牌 | 形成混合策略 |

## 数据持久化

每个 AI 维护独立的数据集：

| 数据 | 存储位置 | 说明 |
|------|---------|------|
| 风格参数 | SQLite | 紧松度、凶弱度、入局率等 |
| 对手画像 | SQLite | 每个对手的统计数据 |
| 学习率 | SQLite | 当前学习率（会衰减） |
| ε值 | SQLite | 探索率（随局数衰减） |

## Definition of Done

- [ ] 5个AI风格参数正确配置
- [ ] AI决策在0.5-1.5s内完成
- [ ] AI只能观测允许的信息
- [ ] 每局结束后正确更新对手画像
- [ ] 每N局后AI参数有调整
- [ ] 学习率随局数正确衰减
- [ ] ε探索率随局数正确衰减
- [ ] AI打法差异可感知（紧凶明显比松弱更紧）
