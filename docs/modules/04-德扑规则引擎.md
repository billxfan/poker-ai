# [[德扑规则引擎]]

## 功能

100% 实现标准无限注德州扑克规则，包括座位、盲注、发牌、下注、边池计算、牌型判定。

---

## 一、牌桌与位置规则

### 1.1 固定6人桌

| 位置 | 简称 | 说明 |
|------|------|------|
| 枪口位 | UTG | 最先行动位置 |
| 中位 | MP | UTG下一位 |
| 关煞位 | CO | 按钮位下一位 |
| 按钮位 | BTN | 庄家位置，发牌起点 |
| 小盲位 | SB | 按钮位左邻 |
| 大盲位 | BB | 小盲位左邻，最后行动 |

**位置顺序（顺时针）**：
```
UTG → MP → CO → BTN → SB → BB → (回到UTG)
```

### 1.2 按钮轮换

每局结束后，按钮位顺时针轮换：

```
BTN → SB → BB → UTG → MP → CO → BTN
```

### 1.3 行动顺序规则

**严格遵循位置规则，无任何顺序偏差。**

| 轮次 | 行动顺序（顺时针） | 说明 |
|------|-----------------|------|
| 预翻牌 | UTG → MP → CO → BTN → SB → BB | 从UTG开始 |
| 翻牌 | SB → BB → UTG → MP → CO → BTN | 从SB开始（按钮位左侧） |
| 转牌 | SB → BB → UTG → MP → CO → BTN | 同翻牌轮 |
| 河牌 | SB → BB → UTG → MP → CO → BTN | 同翻牌轮 |

## 三、发牌与下注轮次

### 3.1 预翻牌轮（Pre-Flop）

```
1. 盲注下注：SB下注10，BB下注20
2. 发底牌：每位玩家发2张私有底牌
3. 行动顺序：从大盲位下一位（UTG）开始，顺时针行动
4. 轮次结束条件：所有活跃玩家下注额相等，或非活跃玩家全部弃牌
```

### 3.2 翻牌轮（Flop）

```
1. 发牌：发出3张公共牌
2. 行动顺序：从按钮位左侧第一位活跃玩家（SB）开始，顺时针行动
3. 轮次结束条件：所有活跃玩家下注额相等，或非活跃玩家全部弃牌
```

### 3.3 转牌轮（Turn）

```
1. 发牌：发出第4张公共牌
2. 行动顺序：同翻牌轮，从SB开始
3. 轮次结束条件：所有活跃玩家下注额相等，或非活跃玩家全部弃牌
```

### 3.4 河牌轮（River）

```
1. 发牌：发出第5张公共牌
2. 行动顺序：同翻牌轮，从SB开始
3. 轮次结束条件：所有活跃玩家下注额相等，或非活跃玩家全部弃牌
```

## 四、玩家行动规则

### 4.1 四种标准操作

| 操作 | 说明 | 规则校验 |
|------|------|---------|
| **弃牌 (Fold)** | 放弃本局牌局，退出后续所有行动 | 无限制，任何时刻可执行 |
| **跟注 (Call)** | 投入与当前轮次最大下注额相等的筹码 | 跟注额 = 当前最大下注额 - 玩家已下额 |
| **加注 (Raise)** | 在当前最大下注额基础上增加下注 | 加注后总额 ≥ 当前最大下注额 + 最小加注额 |
| **全下 (All-in)** | 将自身剩余的所有筹码全部投入底池 | 无限制，任何时刻可执行 |

### 4.2 最小加注额

**最小加注额 = 当前轮次的最大下注额**

（即：加注后总额 = 当前最大下注额 × 2 - 玩家已下额）

```
示例：
当前最大下注额 = 100
玩家已下 = 0
最小加注总额 = 200（最小加注额 = 100）
```

### 4.3 全下（All-in）处理

| 情况 | 处理方式 |
|------|---------|
| 全下额 = 当前最大下注额 | 视为跟注 |
| 全下额 < 当前最大下注额 | 触发边池计算，该玩家只参与主池争夺 |
| 全下额 > 当前最大下注额 | 触发加注，其他玩家需跟注到新下注额或再加注 |

## 五、轮次结束规则

### 5.1 核心原则

**每轮必须所有活跃玩家的下注额完全相等，才可进入下一轮次。**

```
轮次结束条件（同时满足）：
1. 所有活跃玩家的已下筹码相等
2. 或所有非活跃玩家已弃牌
```

### 5.2 下注额一致示意

```
正确示例（轮次可结束）：
  玩家A: 已下100
  玩家B: 已下100  ← 活跃，下注额相等
  玩家C: 已下100  ← 活跃，下注额相等
  玩家D: 弃牌    ← 非活跃，不参与

错误示例（轮次不可结束）：
  玩家A: 已下100
  玩家B: 已下80   ← 活跃，下注额不相等，不能结束
  玩家C: 已下100
```

## 六、胜负判定与底池结算

### 6.1 提前结束

**所有玩家弃牌时，最后剩余的唯一活跃玩家直接赢取全部底池。**

```
示例：
  玩家A: 弃牌
  玩家B: 弃牌
  玩家C: 活跃（最后一个）
→ 玩家C直接获胜，无需摊牌
```

### 6.2 摊牌结算

河牌轮结束后：
```
1. 剩余活跃玩家按行动顺序亮出手牌
2. 按标准德扑10种牌型等级判定胜负
3. 牌力最高者赢取底池
4. 若牌力相同，平分底池
```

### 6.3 主池与边池

#### 主池

所有玩家投入的最低筹码部分汇入主池。

#### 边池

当有玩家全下但筹码少于当前下注额时，触发边池计算。

#### 多边池示例

```
玩家A: 全下100
玩家B: 跟注200
玩家C: 跟注200

主池: 100 × 3 = 300    (所有玩家参与)
边池1: 100 × 2 = 200    (B和C超出A的部分)

若A获胜: A赢得主池300
         B和C继续争夺边池1

若B获胜: B赢得主池300 + 边池1(200) = 500
```

## 七、牌型判定规则

### 7.1 标准牌力排序（从高到低）

| 等级 | 牌型 | 英文 | 说明 |
|------|------|------|------|
| 1 | 皇家同花顺 | Royal Flush | A、K、Q、J、10同花色 |
| 2 | 同花顺 | Straight Flush | 5张同花色顺子 |
| 3 | 四条 | Four of a Kind | 4张相同点数 |
| 4 | 葫芦 | Full House | 3条+1对 |
| 5 | 同花 | Flush | 5张同花色 |
| 6 | 顺子 | Straight | 5张顺子 |
| 7 | 三条 | Three of a Kind | 3张相同点数 |
| 8 | 两对 | Two Pair | 2对 |
| 9 | 一对 | One Pair | 1对 |
| 10 | 高牌 | High Card | 无对子时比最大单张 |

### 7.2 A的两种用法

| 用法 | 说明 | 示例 |
|------|------|------|
| 最大A | A > K > Q > J > 10 > ... > 2 | A-K-Q-J-10 是最大顺子 |
| 最小A | A可作1在A-2-3-4-5顺子中 | A-2-3-4-5 是最小顺子（轮子） |

```
最大顺子: 10-J-Q-K-A  (皇家同花顺)
最小顺子: A-2-3-4-5  (轮子)
A不能同时作最大和最小，必须二选一
```

### 7.3 牌型比较规则

1. 先比牌型等级（1 > 2 > 3 > ... > 10）
2. 同牌型时，比最大单张
3. 最大单张相同，比第二大单张
4. 以此类推，直到比完5张
5. 5张全相同，平分底池

### 7.4 花色

**花色不分大小，仅在同为皇家同花顺时平分底池。**

## 八、数据模型

### Card（一张牌）

```swift
struct Card {
    suit: Suit   // ♠ ♥ ♦ ♣
    rank: Int    // 2-14 (2=2, ..., 14=A)
}
```

### Hand（手牌）

```swift
struct Hand {
    holeCards: (Card, Card)?  // 底牌
    bestFive: [Card]           // 最佳5张组合
}
```

### HandType（牌型枚举）

```swift
enum HandType: Int, Comparable {
    case highCard = 1       // 高牌
    case onePair = 2         // 一对
    case twoPair = 3         // 两对
    case threeOfAKind = 4    // 三条
    case straight = 5        // 顺子
    case flush = 6           // 同花
    case fullHouse = 7       // 葫芦
    case fourOfAKind = 8     // 四条
    case straightFlush = 9   // 同花顺
    case royalFlush = 10     // 皇家同花顺
}
```

### Player（玩家）

```swift
struct Player {
    id: Int
    name: String
    position: Position  // UTG/MP/CO/BTN/SB/BB
    chips: Int          // 剩余筹码
    holeCards: (Card, Card)?  // 底牌
    status: PlayerStatus  // active/folded/allIn/out
}
```

### Action（行动）

```swift
struct Action {
    player: Player
    type: ActionType  // fold/call/raise/allIn/check
    amount: Int       // 投入筹码
    street: Street    // preFlop/flop/turn/river
}
```
