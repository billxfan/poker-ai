## 视觉设计

### 配色方案

| 元素 | 颜色 | 用途 |
|------|------|------|
| 筹码卡片 | `#1E3A5F` 深蓝 | 主色，突出财富感 |
| 每日福利卡片 | `#2E7D32` 深绿 | 已领取状态 |
| 继续游戏按钮 | `#2563EB` 蓝色 | 主要行动 |
| 新开始按钮 | `#7C3AED` 紫色 | 次要行动 |
| 福利中心按钮 | `#DC2626` 红色 | 福利/奖励 |
| 历史统计按钮 | `#64748B` 灰色 | 信息查看 |

### 按钮样式

所有按钮**相同尺寸**，通过颜色和 emoji 区分功能：

```
┌─────────────────────────┐
│  🔵 [图标]  按钮文字    │  ← 48pt 高度，圆角 12pt
└─────────────────────────┘
```

## 按钮行为

| 按钮 | 条件 | 行为 |
|------|------|------|
| **继续游戏** | 有未完成牌局 | 恢复上一局 |
| **继续游戏** | 无存档 | 跳转新局创建流程 |
| **继续游戏** | 筹码 = 0 | 显示弹窗提示 |
| **新开始** | 筹码 > 0 | 弹出确认框 |
| **新开始** | 筹码 = 0 | 显示弹窗提示去福利中心 |
| **福利中心** | 无条件 | 跳转福利中心 |
| **历史统计** | 无条件 | 跳转统计页面（2个Tab） |

## 状态机

### MainView

| 当前状态 | 触发事件 | 动作 | 下一状态 |
|---------|---------|------|---------|
| idle | 进入页面 | 检测筹码余额 | checkingChips |
| checkingChips | 筹码 > 0 | 显示筹码卡片（正常） | idle |
| checkingChips | 筹码 = 0 | 显示筹码卡片（不足） | idle |
| idle | 点击继续游戏 | 检查存档 | checkingSave |
| checkingSave | 存档存在 | 加载并跳转 | GameView |
| checkingSave | 无存档 | 跳转新局 | GameView |
| idle | 点击新开始 | 检查筹码 | checkingChipsForNew |
| checkingChipsForNew | 筹码 > 0 | 弹出确认框 | confirming |
| checkingChipsForNew | 筹码 = 0 | 显示弹窗提示 | noChips |
| noChips | 点击去福利中心 | 跳转 | WelfareView |
| noChips | 点击取消 | 关闭弹窗 | idle |
| confirming | 用户确认 | 重置AI数据，创建新局 | GameView |
| confirming | 用户取消 | 关闭弹窗 | idle |
| idle | 点击福利中心 | 跳转 | WelfareView |
| idle | 点击历史统计 | 跳转 | StatisticsView |

## 异常处理

| 场景 | 策略 |
|------|------|
| 筹码不足 | 筹码卡片变红 + 显示提示文字 |
| 存档数据损坏 | 弹出「存档已损坏」，自动清理损坏存档 |

## 模块依赖

- 依赖：游戏存档系统、AI学习数据系统、福利中心系统、筹码系统
- 被依赖：GameView（局结束后返回）
